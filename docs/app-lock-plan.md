# 0. 어떤 기능인지 설명

0. GroupHomeScreen.tsx의 assets/turtle-fall.png 거북이 이미지를 두 번 탭하면 my-lock-status 페이지로 넘어간다.
1. 우측 상단에 플러스 버튼이 존재한다.
2. 플러스 버튼을 누르면, 유저가 자신의 디바이스에서 잠글 앱을 선택하는 iOS 화면이 뜬다.
3. 잠글 앱들을 선택하고 선택한 앱들의 총 스크린 타임 합(목표 시간)을 설정한다.
4. my-lock-status 페이지에 내가 선택한 앱들의 앱별 현재의 스크린 타임 사용량과 내가 설정했던 목표시간을 띄운다.
